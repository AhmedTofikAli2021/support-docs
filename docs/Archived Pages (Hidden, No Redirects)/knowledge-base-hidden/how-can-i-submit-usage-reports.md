DataCite Clients can submit usage reports for the datasets in their repositories via our usage reports API (https://support.datacite.org/docs/usage-reports-api-guide). These usage reports should follow the COUNTER Codes of Practice relevant for the type of materials in the repository. The DataCite Usage Reports API Guide has more information on how to send usage reports for research data. 

You can find more details about how to provide usage reports in this [blog post] (https://blog.datacite.org/time-to-make-your-data-count/). 

You can also review the California Digital Library use case for detailed steps about the implementation of Make Data Count. Tips and tools (e.g. a Python Log Processor) are detailed in this guide and available on our public Github. 

Links in this guide also point to the DataCite documentation necessary for implementation.
