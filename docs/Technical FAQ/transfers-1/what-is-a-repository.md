Prefixes and DOIs are managed at the repository level. Anew repository environment must be set up in Fabrica before the prefix(es) and DOI can be transferred. Repositories Work in the same way as former client accounts. DataCite defines a repository as a service operated by research organizations, where research materials are stored, managed and made accessible. A repository is a single place (unit) and DataCite will link the repository to information in re3data, where additional repository metadata are available. For more information see our member [documentation](what-is-the-role-of-repositories-in-the-member-model).
