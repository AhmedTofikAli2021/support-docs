Introduction to Metadata 

Metadata is "a small amount of data designed to provide reference information about other data". Metadat is essential so that content can be discovered. There are many different types of metadata and DataCite has its own metadata schema. A metadata schema is a list of relevant criteria to help identify something. Some examples of metadata include:

Title
Author
Subject

DataCite Metadata

The [DataCite metadata schema](http://schema.datacite.org/) is the DataCite standard, developed by the Metadata Working Group. Every propery in the schema is documented.
