> 📘 Get set-up for DOI registration
> 
> Before you can start registering DOIs you need:
> 
> - To be a DataCite Member or part of a DataCite Consortium
> - To set-up a Repository account (this account is the access point for all DOI registration services) 
> - Ensure you can provide the mandatory metadata for your resources, see the DataCite Metadata Schema
> - Host landing pages for your resources

> 📘 Register a DOI and metadata
> 
> There are three ways to register DOIs (and metadata):
> 
> - Create a DOI with the REST API
> - Create a DOI with the form or file upload in DataCite Fabrica
> - Use a registered Service Providers like DSpace, Dataverse, OJS
> - List of supported resource types DOIs can be assigned to

> 📘 Connect ORCID to works shared with DataCite DOIs
> 
> Researchers can connect their ORCID iDs to works with a DataCite DOI:
> 
> - One page guide for researchers
> - ORCID Auto-Update
> - ORCID Search & Link

> 📘 Use metadata to create links between your DOIs and other PIDs
> 
> You can create connections in the metadata:
> 
> - Include ORCID iDs for researchers
> - Create citation counts for your resources
> - Include ROR IDs for affiliated organizations and funders

> 📘 Find metadata
> 
> All the DOI metadata you create is openly available with a CC0 license. You can retrieve metadata:
> 
> - With a search in DataCite Commons
> - By querying the REST API
> - In a third party platform or search engine

There's loads more documentation to explore on the DataCite support site including training, the knowledge base, more DataCite services, APIs and more.

If you can't find the answer you are looking for, contact DataCite support: [support@datacite.org](mailto:support@datacite.org)
