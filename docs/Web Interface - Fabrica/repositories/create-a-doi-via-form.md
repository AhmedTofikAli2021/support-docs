Navigate to the DOIs tab in the Repository dashboard. Click the orange *Create DOI (Form)* button in the upper left of the screen.

Enter the DOI, the state, and the metadata. Draft DOIs need to have only the DOI and the state (selected as Draft). Registered and Findable DOIs need to have all the required metadata fields. At this time, the Fabrica form supports all of the metadata fields in the [DataCite Metadata Schema](https://schema.datacite.org) that are labeled as required, plus the optional Resource Type and Description field. 

For help on filling in each field, please see [Field Descriptions for Form](doc:field-descriptions-for-form) 

For more information on creating DOIs in Fabrica watch this short **[how-to video](https://youtu.be/syBu-JKYA10)**

Once you've filled in the appropriate fields, click the *Create DOI* button at the bottom of the page. Your DOI will be saved in Fabrica, and the record page for the DOI will be displayed.
