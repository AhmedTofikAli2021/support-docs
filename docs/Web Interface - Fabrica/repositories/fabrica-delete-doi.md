It is possible to delete a Draft DOI. First, select the Draft DOI you would like to delete from the list of DOIs on the *DOIs* tab in the Repository dashboard.

Once the DOI is selected, on the DOI record screen, click the *Delete DOI* button. **Note:** The *Delete DOI* button is only available for Draft DOIs. Registered and Findable DOIs cannot be deleted. 
[block:image]
{
  "images": [
    {
      "image": [
        "https://files.readme.io/6466339-Screenshot_2019-04-26_at_13.39.15.png",
        "Screenshot 2019-04-26 at 13.39.15.png",
        1084,
        323,
        "#fbfaf9"
      ],
      "caption": ""
    }
  ]
}
[/block]
You will be asked to confirm DOI deletion by re-entering the DOI to be deleted. You may either type or cut and paste the DOI into the provided field. Click the *Delete* button to finalize deletion. DOI deletion cannot be undone.
