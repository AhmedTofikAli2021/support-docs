Navigate to the DOIs tab on the Repository dashboard. Click the orange *Create DOI (File Upload)* button in the upper left of the screen.

Enter the DOI, the state, and the metadata. For detailed explanations of each field, see [Field Descriptions for the File Upload Screen](doc:fields-file-upload).

Once you've filled in the appropriate fields, click the *Create DOI* button at the bottom of the page. Your DOI will be saved in DOI Fabrica, and the record page for the DOI will be displayed.
