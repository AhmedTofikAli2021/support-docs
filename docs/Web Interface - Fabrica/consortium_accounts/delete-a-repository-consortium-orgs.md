It is possible for a Consortium or a Consortium Organization to delete their Repositories. 

If the Repository has registered DOIs, the Consortium or Consortium Organization must first [transfer the DOIs](doc:transfer-dois-between-clients) to another Repository managed by the same Consortium Organization.

After any remaining DOIs have been transferred, go to the Repository tab of the Consortium Organization dashboard and click on the name of the Repository to be deleted.

You will not be able to delete a Repository that still has associated DOIs. When you click on *Delete Repository*, you will instead see the screen below, asking you to first transfer all DOIs to another Repository.

Click on *Transfer DOIs* to initiate the DOI transfer, described in [Transfer DOIs Between Repositories](doc:transfer-dois-between-clients).
