Consortium and Consortium Organization accounts can update the settings of their Repositories. 

To modify the Repository settings, go to the Settings tab in the Repository dashboard. Select the Repository from the list of Repositories in order to view the appropriate Repository dashboard. Click the *Update Repository* button in the upper right.

Enter any changes in the appropriate fields and click *Save* at the bottom of the page. **Note:** The Repository ID is fixed at time of Repository creation and cannot be changed. 

For detailed descriptions of the fields, see [Field Descriptions for Repository Settings](doc:fields-client-settings).
