When you log in with the Consortium credentials you will see the dashboard with 5 tabs: Info, Settings, Consortium Organizations, Repositories, DOIs.
[block:api-header]
{
  "title": "Info"
}
[/block]
The *Info* tab gives an overview. The three charts display the total number of Consortium Organizations, Repositories and the total number of DOIs created in the current year across all of the Repositories.

[block:api-header]
{
  "title": "Consortium Organizations"
}
[/block]
The **Consortium Organizations** tab lists all of the organizations under that particular Consortium. The default sorting order is by *Name*. To change sorting order to sort by *Date joined*, click on the arrow in the dropdown box at the top of the Consortium Organization list and select *Sort by Date Joined*. To search for an individual Consortium Organization, enter the name or the ID of the Consortium Organization in the search box and click *Search*. 

To filter the Consortium Organization list by year joined, select the appropriate box on the right side of the screen. To deactivate the filter, re-click the selected box.

[block:api-header]
{
  "title": "Repositories"
}
[/block]
The *Repositories* tab lists all of the Repositories. The Repository information including the Repository ID and system email can be viewed here. Consortium leads cannot create repositories in this view. Click on the Consortium Organization first.

The default sorting order for  Repositories is by *Name*. To change sorting order to sort by *Date joined*, click on the arrow in the dropdown box at the top of the Repository list and select *Sort by Date Joined*. To search for an individual Repository, enter the Repository name or the Repository ID in the search box and click *Search*. 

To filter the Repository list by year joined, select the appropriate box on the right side of the screen. To deactivate the filter, re-click the selected box.

[block:api-header]
{
  "title": "DOIs"
}
[/block]
The *DOI* tab lists all the DOIs registered by all Repositories. Information about the DOIs appears in the facets on the left, this includes; State, Resource Type, Year Created, Year Registered (in the global handle system), Repository, Affiliation, Prefix, Repository Certificate, Schema Version, Source and Link Check Status. The search form can be used to find an individual DOI.
