## About the data file for the Data Citation Corpus

The [Data Citation Corpus](https://makedatacount.org/data-citation/) is a project by DataCite and Make Data Count funded by the [Wellcome Trust](https://datacite.org/make-data-count-a-central-corpus-for-all-data-citations/), which has as its focus the development of a comprehensive, centralized and publicly-available resource of data citations from a variety of sources. 

Corpus data is available as a data file on [Zenodo](https://zenodo.org/doi/10.5281/zenodo.11196858) and via a [public dashboard](https://corpus.datacite.org).

For more information about the corpus, visit the [Make Data Count website](https://makedatacount.org/find-a-tool/data-citation-corpus-documentation/).

Feedback on the data file can be submitted via [GitHub](https://github.com/Make-Data-Count-Community/data-citation-corpus-feedback). For general questions, email [info@makedatacount.org.](mailto:info@makedatacount.org.)
