## The DataCite Metadata Schema

The DataCite Metadata Schema is a list of core metadata properties chosen for accurate and consistent identification of a resource for citation and retrieval purposes, with recommended use instructions in the documentation.

All DataCite Metadata Schema documentation is available on the schema website: <https://schema.datacite.org/>.

## DataCite Metadata Schema 4.5

The latest minor version of the DataCite Metadata Schema is Schema 4.5, released on January 22, 2024.

Documentation for this version is hosted on Read the Docs: <https://datacite-metadata-schema.readthedocs.io/en/4.5/>.

Documentation and examples can be accessed from the schema website: <https://schema.datacite.org/meta/kernel-4.5/>
