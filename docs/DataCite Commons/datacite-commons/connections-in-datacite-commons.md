# Connections

Works, people, and organizations—and the connections between them—are searchable via DataCite Commons and the DataCite GraphQL API .

DataCite Commons shows the following connections:

* Works: references, citations, views, and downloads
* People: works
* Organizations: works

The references and citations, shown for works come via related identifier information from DataCite and Crossref DOI metadata.

The views and downloads shown for works come via usage reports following the [COUNTER](https://www.projectcounter.org/) standard submitted from [repositories to DataCite](doc:views-and-downloads).

The works shown for people come via creator name identifier information from DataCite and Crossref DOI metadata.
