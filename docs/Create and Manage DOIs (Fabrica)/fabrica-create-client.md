Providers are able to create new Client accounts and manage existing accounts. Every Client accessing Fabrica through an associated Provider must have their own account. 

To add a new Client, go to the Clients tab of the Provider dashboard and click the *Add Client* button on the left. Fill in the requested details and click *Save* at the bottom of the record. A system email with the Client ID and a link to set up a password will automatically be sent to the contact email that you specified in the Client settings.

For detailed explanations of each field, see [Field Descriptions for Client Settings](doc:fields-client-settings).
