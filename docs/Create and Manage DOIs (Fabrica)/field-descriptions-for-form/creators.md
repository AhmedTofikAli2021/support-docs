The Creators field is where you add the information about the authors of the content. This field is required. 

A creator can be:
  * the **name(s)** of the author(s) of the content, or; 
  * an **organization** that created the content
[block:callout]
{
  "type": "info",
  "body": "You can include up to 25 creators when you create a DOI via the Form."
}
[/block]

##Names

There are two ways to add the name of the creator in the form:

1. Add a Name Identifier, like an ORCID to auto-populate the name fields. The identifier must be entered as a URL, e.g. https://orcid.org/0000-0003-1419-2405. Note that when using this method the name fields will not be editable, so as to avoid any accidental incorrect attribution.

Multiple creators can be included by clicking on the "Add another creator" button.

##Organizations

To add an organization as the creator select "Organization" using the radio button and type the name in the field below. 

Organizations can also have affiliations, for example if the main organization is a project or working group, rather than a formal organization. 

You can add multiple affiliations.
