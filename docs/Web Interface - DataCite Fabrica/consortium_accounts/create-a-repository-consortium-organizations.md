Consortium and Consortium Organization accounts are able to create new Repository accounts and manage existing accounts. Every Repository accessing Fabrica through an associated Consortium Organization must have their own account. 

To add a new Repository, go to the Repositories tab on the Member dashboard and click the *Add Repository* button on the left. Fill in the requested details and click *Save* at the bottom of the record. An email with the Repository ID and a link to set up a password will automatically be sent to the system email that you specified in the Repository settings.

For detailed explanations of each field, see [Field Descriptions for Repository Settings](doc:fields-client-settings).
