Log in with the Consortium lead credentials to manage Consortium Organizations and their Repositories. There are 7 tabs on the Consortium dashboard: Info, Settings, Consortium Organizations, Contacts, Repositories, Prefixes and DOIs. 

## Info

The first tab displayed after logging into Fabrica is the _Info_ tab. The charts give an overview of the total number of Consortium Organizations, Repositories and the total number of DOIs created in the current year across all of the Repositories. The "Role: Consortium" is the type of account. 

On the top right of the page are links to the Fabrica "About" and "Support" sections as well the account "Role", a link to the "settings" and the "Sign Out" option.

## Consortium Organizations

The **Consortium Organizations** tab lists all of the organizations under that particular Consortium. The default sorting order is by _Name_. To change sorting order to sort by _Date joined_, click on the arrow in the dropdown box at the top of the Consortium Organization list and select _Sort by Date Joined_. To search for an individual Consortium Organization, enter the name or the ID of the Consortium Organization in the search box and click _Search_. 

To filter the Consortium Organization list by year joined, select the appropriate box on the right side of the screen. To deactivate the filter, re-click the selected box.

![](https://files.readme.io/53933a6-Screenshot_2023-01-25_at_13.53.21.png "Screenshot 2023-01-25 at 13.53.21.png")

## Contacts

The Contacts tab lists all of the Consortium contacts. The contact Name, Email, Roles and Date Created are displayed here. Click on the "Add Contact" button on the left to [add new organizational contacts](doc:add-contacts-in-fabrica-consortia).

![](https://files.readme.io/5dc9de6-Screenshot_2023-01-25_at_13.54.12.png "Screenshot 2023-01-25 at 13.54.12.png")

## Repositories

The _Repositories_ tab lists all of the Repositories. The Repository information including the Repository ID and system email can be viewed here. Consortium leads cannot create repositories in this view. Click on the Consortium Organization first.

The default sorting order for  Repositories is by _Name_. To change sorting order to sort by _Date joined_, click on the arrow in the dropdown box at the top of the Repository list and select _Sort by Date Joined_. To search for an individual Repository, enter the Repository name or the Repository ID in the search box and click _Search_. 

To filter the Repository list by year joined, select the appropriate box on the right side of the screen. To deactivate the filter, re-click the selected box.

## Prefixes

The DOI prefix is used as a namespace so DOIs are globally unique without requiring global coordination for each new identifier. All DOI prefixes are numbers without any semantic meaning.

The Prefixes tab contains a list of all prefixes assigned to a Member. A new prefix is assigned automatically when a [new Repository is created](doc:create-a-repository-consortium-organizations).

![](https://files.readme.io/cafc883-Screenshot_2023-01-25_at_13.59.24.png "Screenshot 2023-01-25 at 13.59.24.png")

## DOIs

The _DOIs_ tab lists all the DOIs registered by all Repositories. By default the list is sorted by Date Updated but can be sorted by: Date Created, DOI, Alphabetically or by Relevance.

Information about the DOIs appears in the facets on the left, this includes; State, Resource Type, Year Created, Year Registered (in the global handle system), Repository, Affiliation, Prefix, Repository Certificate, Schema Version, Source and Link Check Status. The search form can be used to find an individual DOI.

## Export DOI Metadata

On the left of the DOIs tab is the **Export DOI Metadata** button. Click here to export a CSV file containing the basic metadata of all of the DOIs in the list.

![](https://files.readme.io/42d8660-Screenshot_2023-01-25_at_14.02.57.png "Screenshot 2023-01-25 at 14.02.57.png")

> 📘 
> 
> Only the 25 records on the current page view will be exported. To export more records you need to scroll through to the next page.

## Researcher Profiles

When the ORCID iD is included in the DOI metadata the creator name will appear as a link in the DOI list. Click on the link to be taken to the corresponding research profile in [DataCite Commons](https://commons.datacite.org/).

![](https://files.readme.io/24e3706-Screenshot_2023-01-26_at_10.12.39.png "Screenshot 2023-01-26 at 10.12.39.png")

The researcher profile in DataCite Commons displays information linked to the ORCID record.
