You can export DOI metadata from the _DOIs_ tab. Click the "Export DOI Metadata" button to export a CSV file containing the basic metadata of the DOIs in the list.

Only the 25 records on the page view will be exported. To export more records, scroll through to the next page.

The CSV file will include the basic DOI metadata properties for the DOIs in the list, including:

- doi
- url
- registered (date)
- state
- resourceTypeGeneral
- resourceType
- title
- author
- publisher
- publicationYear
