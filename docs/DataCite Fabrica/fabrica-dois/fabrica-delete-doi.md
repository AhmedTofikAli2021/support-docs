Repositories can delete [Draft records](doc:doi-states#draft-records) in DataCite Fabrica. 

First, select the Draft record you would like to delete from the list in the _DOIs_ tab in the Repository dashboard. Use the State filter on the left to select only "Drafts".

Once the Draft is selected, click "Delete DOI" on the left. 

> 🚧 Only Draft records can be deleted
> 
> The "Delete DOI" button is only available for Draft records. Registered and Findable DOIs cannot be deleted. For more information, see [DOI States](doc:doi-states) .
> 
> Only Repositories can delete Draft records. If you're not seeing the Delete DOI button, make sure you're logged in with a [Repository account](doc:datacite-account-types#repository-account).

![](https://files.readme.io/6466339-Screenshot_2019-04-26_at_13.39.15.png "Screenshot 2019-04-26 at 13.39.15.png")

You will be asked to confirm deletion by re-entering the identifier to be deleted. Click "Delete" to finalize deletion. 

Deletion cannot be undone and the same identifier cannot be reused once deleted.
