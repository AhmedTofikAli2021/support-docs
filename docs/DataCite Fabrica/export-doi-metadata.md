The Export **DOI Metadata button** appears on the left of the DOIs tab in Fabrica when logged in with a Direct Member, Consortium Lead, Consortium Organization or Repository account.

Click the button to export a CSV file which contains the basic metadata records of all of the DOIs listed in the DOIs tab.
