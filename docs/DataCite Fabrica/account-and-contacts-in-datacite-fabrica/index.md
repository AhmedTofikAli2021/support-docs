DataCite members can use Fabrica to:

- **Create and update contacts**: Members can update contacts in the [contacts tab](docs:fabrica-contacts)
- **Update settings:** Add and update important organizational information in the [settings tab](doc:fabrica-settings)
- **Create Repository accounts** : create and update Repository accounts  [Repositories tab](doc:fabrica-repositories)
- **Create and Manage Consortium Organizations:** Consortium Leads can [create and manage Consortium Organizations](doc:fabrica-consortium-organizations)
