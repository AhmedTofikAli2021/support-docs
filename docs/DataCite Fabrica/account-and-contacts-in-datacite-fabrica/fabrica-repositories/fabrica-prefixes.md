When a new Repository is created, a DOI [prefix](doc:doi-basics#prefix) is automatically assigned to that Repository account. By default, each Repository has one prefix.

The _Prefixes_ tab in DataCite Fabrica shows a list of your account's prefixes. If your account has multiple prefixes, you can search prefixes and:

- Filter by whether or not the prefix has been assigned to a repository ("State").
- Filter by year created.
- Consortium Leads can filter by which Consortium Organization the prefix is associated with.

> 📘 About additional prefixes
> 
> A Repository account in DataCite has one prefix which is assigned automatically when the account is created. 
> 
> A DataCite Member or Consortium Organization may have as many Repository accounts as needed. We recommend creating a new Repository account for a group of resources that will stay together. 
> 
> If you need to add additional prefixes to an existing Repository account, please contact us at [support@datacite.org](mailto:support@datacite.org).
