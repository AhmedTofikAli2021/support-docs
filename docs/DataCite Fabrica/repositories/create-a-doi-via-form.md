The **Create DOI** button appears on the left hand side of all of the tabs on the Repository dashboard. Click the *Create DOI* button to go directly to the Form or hover over the *Create DOI* button and click *DOI Form* to register a new DOI using the Form.

The DOI name appears at the top of the page. The suffix is automatically generated (this is the recommended option, but it can be edited). Select the state and then enter the metadata. Draft state does not require metadata, only the identifier and the state (selected as Draft). Registered and Findable DOIs need to have all the required metadata fields. The fields in the Form correspond to the [DataCite Metadata Schema](http://schema.datacite.org/).

For help on filling in each field, please see [Field Descriptions for Form](doc:field-descriptions-for-form) 

For more information on creating DOIs in Fabrica watch this short **[how-to video](https://youtu.be/syBu-JKYA10)**

Once you've filled in the appropriate fields, click the *Create DOI* button at the bottom of the page. Your DOI will be saved in Fabrica, and the record page for the DOI will be displayed.
