The Create DOI button appears on the top left of all the tabs on the Repository dashboard. Hover over the _Create DOI_ button and then click _File Upload_.

The DOI name appears at the top of the page. The suffix is automatically generated (this is the recommended option, but it can be edited).  For detailed explanations of each field, see [Field Descriptions for the File Upload Screen](doc:fields-file-upload).

Once you've entered the metadata, either by pasting it into the file upload window or by clicking the Upload File button click the _Create DOI_ button at the bottom of the page. Your DOI will be saved in Fabrica, and the record page of the DOI will be displayed.

> 🚧 When will the DOIs I created show up in DataCite Commons?
> 
> Findable DOIs will be indexed in DataCite Commons within 15 minutes of being created in DOI Fabrica.
