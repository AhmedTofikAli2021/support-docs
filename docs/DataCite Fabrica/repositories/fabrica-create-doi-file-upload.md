File Upload is accessed through the "Create DOI" button, which appears on the left side of all tabs of the Repository dashboard. Click the arrow next to the "Create DOI" button and select "File Upload".

Select the state and then enter the metadata. Draft state does not require metadata, only the identifier and the state (selected as Draft). Registered and Findable DOIs need to have all the required metadata fields.

For detailed explanations of each field, see [Field Descriptions for the File Upload Screen](doc:fields-file-upload).

Once you have entered the metadata—either by adding it to the text box or through "Upload File"—click the "Create DOI" button at the bottom of the page. Your DOI will be saved and the DOI record page will be displayed.

> 🚧 When will the DOIs I created show up in DataCite Commons?
> 
> Findable DOIs will be indexed in DataCite Commons within 15 minutes of being created in DataCite Fabrica.
