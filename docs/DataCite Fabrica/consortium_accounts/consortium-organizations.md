Both Consortium Organizations and Consortium Leads can update Consortium Organization accounts.

**Consortium Organizations** need to log into Fabrica with their Consortium Organization ID to create and manage Repository accounts. Consortium Organization accounts can **create and manage Repositories and prefixes**.

**Consortium Leads** manage Consortium Organizations through the Consortium Lead Dashboard, which contains the functionality described in this section for all Consortium Organizations within their Consortium.
