Before any transfer can take place, the following information must be sent to [support@datacite.org](mailto:support@datacite.org): 

Old Repository [ID: DATACITE]
New Repository ID: [DATACITE.DATACITE]
Prefix: [10.7000]
Number of DOIs: [165]

Once this information is provided you are ready to schedule the transfer. For more information about prefixes see our documentation [here](doc:doi-basics#section-prefix).
