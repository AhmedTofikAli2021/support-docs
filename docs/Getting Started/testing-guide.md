Test accounts allow users to try out DataCite services in a safe sandbox environment. A test account allows you to configure your systems to automatically register and manage DOIs via one of our APIs or to try out the latest functionality in DOI Fabrica without the risk of creating live DOIs. 

The following sections describe how to get started with testing DataCite services. 
* [Getting a test account](doc:getting-a-test-account)
* [Create a Repository in Fabrica Test](doc:create-a-client-in-fabrica-test)
[block:api-header]
{
  "title": "About the test system"
}
[/block]
DataCite maintains test instances of its services. These test instances can be identified by the word "test" in their URL. These test services are:
* DOI Fabrica (https://doi.test.datacite.org)
* REST API (https://api.test.datacite.org)
* MDS API (https://mds.test.datacite.org)
* EZ API (https://ez.test.datacite.org)

In other words, the test account credentials will allow you to test creating and managing DOIs manually in a web-based platform (DOI Fabrica), and the same set of credentials will allow you to test your own applications and integrations that call one of DataCite's APIs. 
[block:api-header]
{
  "title": "Who can have a test account?"
}
[/block]
Current DataCite Members can have test accounts, as can potential new members.
