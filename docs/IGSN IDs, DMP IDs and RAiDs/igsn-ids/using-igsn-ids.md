An IGSN ID is a globally unique and persistent identifier for physical samples. An IGSN ID can be applied to an individual sample, an aggregation of samples, or to a feature-of-interest (the real-world feature that the sample is taken from). The below pages outline the main use cases for IGSN IDs, as well as some of the aspects that you may need to consider when setting up your IGSN ID registration workflow.

Note that these are 'typical' use cases and considerations. We recognize that there are likely others that are not listed, and we are keen to learn about and explore these with the community. If you have any potential IGSN ID use cases that you would like to discuss or any questions before putting your IGSN ID registration workflow in place, please contact Rorie Edmunds, Samples Community Manager ([rorie.edmunds@datacite.org](mailto:rorie.edmunds@datacite.org)).
