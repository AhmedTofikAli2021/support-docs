IGSN IDs can only be registered with a designated IGSN ID Catalog Repository. Follow these steps to create an IGSN ID Catalog Repository for material samples:

1. Log in to Fabrica as a Direct Member, Consortium Organization, or Consortium Lead.
2. In the Repositories tab of a Direct Member or Consortium Organization, click the "Add Repository" button. 
3. On the "Add Repository" page, select "IGSN ID Catalog" option from the Type dropdown list. For IGSN ID Catalogs, the Type cannot be changed later.

4. Fill in other mandatory and optional fields.
5. Click the "Add Repository" button to create a new designated IGSN ID Catalog Repository account and prefix.

**This Repository must be used exclusively to register IGSN IDs for material samples.** Additional designated IGSN ID Catalog Repositories can be created as well.
