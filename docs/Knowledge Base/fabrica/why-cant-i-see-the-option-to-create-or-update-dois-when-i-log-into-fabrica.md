You can access Fabrica with different types of accounts. Each account has different permissions. If you log into Fabrica with a Member or Consortium Organization account (e.g. OSDV), you have permission to update contacts and create Repositories.

However, you won’t be able to create DOIs. To create DOIs and metadata, you must use your Repository account e.g. OSDV.CLTNJL (this also applies to the DataCite APIs).
