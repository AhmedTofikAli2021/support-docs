ORCID IDs can be added to the DataCite metadata to create a link between the DOI record and the ORCID record. Unlike other related identifiers, the ORCID is added to either the “creator” or the “contributor” fields. When an ORCID is added to the “creator” field, the DOI record can be automatically linked to the ORCID profile of the author via the ORCID auto-update service as long as the author has given DataCite permission once.The dashboard of the newly released DataCite Commons shows all DOIs linked to a person e.g: https://commons.datacite.org/orcid.org/0000-0003-1419-2405
