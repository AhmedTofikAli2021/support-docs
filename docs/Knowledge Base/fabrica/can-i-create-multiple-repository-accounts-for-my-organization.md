Repository accounts in DataCite work as a store where all of the metadata for a group of resources will stay together. This could be a collection of datasets from a repository platform, a departmental database or project, or even a group of samples. Each Repository account has its own prefix.

As a DataCite Direct Member or Consortium Organization, you can log in to DataCite Fabrica to [create new Repository accounts](doc:fabrica-repositories) when you need them. There is no additional cost for additional Repository accounts.

When creating the account, consider that the system email contact in the account settings is the person who receives the set password email. 

Remember, only a Repository account can be used for DOI registration with both DataCite Fabrica and the API.

[Learn more about the different types of accounts in DataCite](doc:datacite-account-types)
