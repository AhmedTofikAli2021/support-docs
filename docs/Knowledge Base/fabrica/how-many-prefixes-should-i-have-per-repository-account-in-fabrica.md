We recommend that each repository account should have one prefix. When a new repository account is created, a new prefix must be assigned. It is not possible to share a prefix between multiple repositories. Each DataCite Member or Consortium Organization may have as many repository accounts (and prefixes) as needed. We recommend creating a new repository account and prefix for a group of resources that will stay together. This makes it easier to move content around if needed in future.
