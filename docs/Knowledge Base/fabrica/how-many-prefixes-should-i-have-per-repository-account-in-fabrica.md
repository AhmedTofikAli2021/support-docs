Each Repository has one prefix. When a new Repository account is created a new prefix is automatically assigned. It is not possible to share a prefix between multiple Repositories. Each DataCite Member or Consortium Organization may have as many Repository accounts as needed. We recommend creating a new Repository account and prefix for a group of resources that will stay together. This model makes it easier to move content around if needed in future.
