In Fabrica every type of account has a mandatory system email contact. This is the primary email address that you would like DataCite to send password reset requests. If you have a generic shared email address (such as info@yourdomain.org or similar), you may use that here. 

You can generate a password reset at anytime here [https://doi.datacite.org/reset ](https://doi.datacite.org/reset) and an email will be sent to the system email contact. 
[block:callout]
{
  "type": "info",
  "body": "Updating the system email contact doesn't automatically send an email to the new contact. You need to trigger a password reset."
}
[/block]
