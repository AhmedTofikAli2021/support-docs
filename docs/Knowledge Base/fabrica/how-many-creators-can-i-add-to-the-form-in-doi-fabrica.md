You can include up to 25 creators when you create a DOI using the [DOI form in Fabrica](doc:fabrica-doi-form). The limit of 25 is an intentional limitation of the Fabrica web form, as most metadata with lots of authors will most likely be updated via an API.

If you are using Fabrica and would like to include more than 25 creators, use the [file upload](doc:fabrica-doi-file-upload) functionality to include as many creators as you need in the metadata. 

We recommend using the [test environment](testing-guide) until you are comfortable creating DOIs.
