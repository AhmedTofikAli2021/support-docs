Direct Members, Consortium Leads and Consortium Organizations can log in to DataCite Fabrica and set up new Repository accounts. When you click on “Add Repository” you will notice that the ID is automatically populated. The first part of the ID corresponds to that of the associated Member or Consortium Organization account and the second part after the dot is a random string, so it will look something like this:

**IMWZ.MONFQK**

We recommend you use the auto-generated format. The Repository ID cannot be changed once you have created it, however all of the other metadata about the Repository, including the name and system email contact can be updated at any time. The opaque format of these IDs means that there is no meaning associated with the ID itself and therefore allows more freedom to move the Repository account to a different Member or Consortium if needed in future.
