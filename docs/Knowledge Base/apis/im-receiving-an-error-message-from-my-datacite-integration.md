If you are receiving an "unauthorized" or "access denied" or 403 error message, this means there is a problem with either the prefix/ID or password.

1. You should be using a repository account, these are normally in the format of "xxx.xxx"
2. Account passwords  and prefixes are normally different between test and the production system.
3. You can always check your login credentials using the Fabrica web admin
Test: https://doi.test.datacite.org​
Production: https://doi.datacite.org 
4. If this is still not working, try resetting your password for your repository here
Test: https://doi.test.datacite.org/reset​
Production: https://doi.datacite.org/reset
