A DataCite Repository account corresponds to a service operated by research organizations, where research materials are stored, managed and made accessible. The Repository account has one unique prefix. This is account used to create and manage DOIs and metadata. Each DataCite Member or Consortium Organization can create Repository accounts.

Read more about Repositories in this [blog post.](https://doi.org/10.5438/xafc-2c88)
