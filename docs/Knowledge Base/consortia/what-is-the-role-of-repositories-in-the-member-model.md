Repositories play a key role in the DataCite member model. We define a Repository as a service operated by research organizations, where research materials are stored, managed and made accessible. A Repository is a single unit. We recommend assigning only one prefix per Repository.

Read more about Repositories in this [blog post](https://blog.datacite.org/the-why-what-and-how-of-repositories/)
