Repositories play a key role in the DataCite membership model. We define a repository as a service operated by research organizations, where research materials are stored, managed and made accessible. A repository is a single unit. In DataCite, this corresponds to a Repository account which has one unique prefix. This is account used to create and manage DOIs and metadata. Each DataCite Member or Consortium Organization can create Repository accounts.

Read more about Repositories in this [blog post.](https://doi.org/10.5438/xafc-2c88)
