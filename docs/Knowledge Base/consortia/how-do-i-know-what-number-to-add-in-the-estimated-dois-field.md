As a  Consortium Lead, when you create a new Consortium Organization account you will need to include the estimated number of DOIs for the first year. The DOI fee is billed based on the DOI estimate for the first year. 

It’s important to note the following when estimating the number of DOIs:

- There is no credit (refund of fees)  if the number of DOIs registered is lower than the estimated DOIs, so we recommend you take this into account when entering an estimate. 
- There is also no additional charge if you register more DOIs than estimated. This will be reflected next year as we will invoice you the following year based on the previous year’s DOI registration.
