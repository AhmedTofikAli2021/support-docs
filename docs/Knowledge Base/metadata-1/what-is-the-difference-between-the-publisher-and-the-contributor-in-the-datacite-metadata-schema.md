In the DataCite metadata schema, the Publisher is the name of the entity that holds, archives, publishes prints, distributes, releases, issues, or produces the resource. This property will be used to formulate the citation, so consider the prominence of the role. The Contributor is the institution or person responsible for collecting, managing, distributing, or otherwise contributing to the development of the resource. For all information about the DataCite Metadata Schema please refer to this [page](http://schema.datacite.org/). For information about the latest version of the schema (4.3) click "More Info". You can download a [PDF](http://schema.datacite.org/meta/kernel-4.3/doc/DataCite-MetadataKernel_v4.3.pdf) with the complete definitions for every metadata field. You can also review changes to the schema and see examples.
