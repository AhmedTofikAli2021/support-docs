In the DataCite Metadata Schema, the Publisher is the name of the entity that holds, archives, publishes prints, distributes, releases, issues, or produces the resource. This property will be used to formulate the citation, so consider the prominence of the role. The Contributor is the institution or person responsible for collecting, managing, distributing, or otherwise contributing to the development of the resource. For all information about the DataCite Metadata Schema please refer to this [page](http://schema.datacite.org/).
