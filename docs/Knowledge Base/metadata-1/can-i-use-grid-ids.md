The [GRID service has been retired](https://www.grid.ac/). We recommend transitioning to use [ROR IDs](https://ror.org/) for both affiliationIdentifier and funderIdentifier [metadata properties](http://schema.datacite.org/). You can find resources about transitioning from GRID to ROR on the [ROR support site](https://ror.readme.io/docs/map-other-organization-id-types-to-ror).
