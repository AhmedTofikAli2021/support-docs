The resourceTypeGeneral is one of the required metadata fields for registering a DOI. The list of resource types can be found in the [DataCite Metadata Schema documentation](https://datacite-metadata-schema.readthedocs.io/en/4/appendices/appendix-1/resourceTypeGeneral/). It is a controlled vocabulary list and includes:

Audiovisual  
Award  
Book  
BookChapter  
Collection  
ComputationalNotebook  
ConferencePaper  
ConferenceProceeding  
DataPaper  
Dataset  
Dissertation  
Event  
Image  
InteractiveResource  
Instrument  
Journal  
JournalArticle  
Model  
OutputManagementPlan  
PeerReview  
PhysicalObject  
Poster  
Preprint  
Presentation  
Project  
Report  
Service  
Software  
Sound  
Standard  
StudyRegistration  
Text  
Workflow  
Other
