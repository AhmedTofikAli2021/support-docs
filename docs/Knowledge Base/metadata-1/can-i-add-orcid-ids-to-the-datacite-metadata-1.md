ORCID IDs can be added to DataCite DOI metadata to create a link between a DOI record and an ORCID record. Unlike other related identifiers, the ORCID is added to either the “creator” or the “contributor” fields. When an ORCID is added to the “creator” field, the DOI record can be automatically linked to the ORCID profile of the author via the ORCID auto-update service as long as the author has given DataCite permission. People pages in DataCite Commons  will also display all DOIs linked to an ORCID record in the "creator" field, e.g: <https://commons.datacite.org/orcid.org/0000-0003-1419-2405>.
