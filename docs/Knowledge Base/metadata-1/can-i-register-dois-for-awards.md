[Schema Version 4.6](https://datacite.org/blog/announcing-datacite-metadata-schema-4-6/) of the [DataCite Metadata Schema](https://schema.datacite.org/) includes support for DOIs for Awards. To improve the discoverability of awards the new schema version includes a dedicated [resourceTypeGeneral value for “Award”](https://datacite-metadata-schema.readthedocs.io/en/4.6/appendices/appendix-1/resourceTypeGeneral/#award) as an umbrella term for funding, grants, scholarships, and other types of awards.

DataCite has worked with pilot organizations on metadata mapping and to develop these [guidelines for registering DataCite DOIs for awards](https://support.datacite.org/docs/registering-datacite-dois-for-awards). These guidelines support key use cases such as output tracking and landscape analysis.  
As a DataCite Member you can already implement Award DOI workflows using your normal DOI registration set-up following the guidelines above.
