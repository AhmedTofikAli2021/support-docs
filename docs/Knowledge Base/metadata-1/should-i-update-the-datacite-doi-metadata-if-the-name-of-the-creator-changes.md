The DataCite metadata should always reflect the latest, correct information. For example, if the “Creator” name changes, the DataCite DOI metadata should also be updated so the citation is accurate. All of the DOI metadata properties can be updated once the DOI has been registered. The URL that the DOI points to can also be updated at any time if needed. The only thing that cannot be changed is the DOI string e.g. (10.5438/me1p-cg09).
