The DataCite metadata should always reflect the latest, correct information. So if the “Creator” name changes, the DataCite DOI metadata should also be updated so the citation is accurate. All of the DOI metadata properties can be updated once the DOI has been registered, including the URL. The only thing that cannot be changed is the DOI name.
