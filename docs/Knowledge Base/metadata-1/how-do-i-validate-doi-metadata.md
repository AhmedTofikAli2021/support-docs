You can check your XML metadata validates correctly against the [DataCite Metadata Schema](http://schema.datacite.org/) using the [XSD file](https://schema.datacite.org/meta/kernel-4.5/metadata.xsd).

Alternatively, you can use [Fabrica](https://doi.test.datacite.org/). Log in with your repository account and navigate to the DOIs tab where you will see the Create (File Upload) option on the left. Paste or load your XML file in the file upload window. Remember to change the state to findable (there is no metadata validation  draft state metadata). If there are any errors the metadata turns red and an error message appears indicating where the error is, once you edit the file and correct errors, the metadata appears in green and you can create a new DOI.

For more information watch this [quick tutorial](https://www.youtube.com/watch?v=xrBv9Q3l6GA&t=106s)
