To showcase and expose metadata, DataCite provides an integrated search interface, [DataCite Commons](https://commons.datacite.org/), where you can search, filter, and extract all the details from a collection of millions of records. This interface is complemented by our [REST API](doc:api) and [OAI-PMH service](doc:datacite-oai-pmh), providing machine actionable end-point to harvest DataCite’s metadata collection.

DataCite metadata are also harvested by various services. For more information, see the [DataCite Metadata Harvesters](https://datacite.org/datacite-metadata-harvesters/) list on our website.
