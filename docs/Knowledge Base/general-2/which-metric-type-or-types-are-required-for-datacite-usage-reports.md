To submit usage reports about views and downloads for the content in your repository you need to be familiar with the [Counter Code of Practice](https://www.projectcounter.org/code-of-practice-rd-sections/abstract/) for Research Data, which standardizes the generation and distribution of usage metrics for research data. 

[Section 4: reports](https://www.projectcounter.org/code-of-practice-rd-sections/4-reports/) describes four metrics that can be submitted to DataCite: Total Dataset Investigations, Total Dataset Requests, Unique Dataset Investigations and Unique Dataset Requests. 

All four of these metrics should be sent to the [DataCite usage reports API](doc:usage-reports-api-guide). The metrics can be [accessed via different DataCite Services](doc:consuming), for example in [DataCite Commons](doc:datacite-commons) you can see counts for unique views and downloads in the metrics counters. In DataCite services a dataset investigation is a view, and a dataset request is a download.

More information about [usage reports for views and downloads](doc:views-and-downloads).
