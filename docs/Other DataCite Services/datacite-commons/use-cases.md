Limits:

Creators/Contributors
There is an upper limit of 20 creators or contributors that can be displayed in DataCite Commons for a DOI record, as you can image some records have very large numbers of creators/contributors, so it is necessary to set a limit for display purposes. 
 
As you noted you can download the full metadata record in JSON and XML or retrieve it via our API: https://api.datacite.org/dois/10.48688/g1vx-1k81
