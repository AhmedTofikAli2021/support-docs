Access the DataCite Citation Formatter here: [http://citation.crosscite.org](http://citation.crosscite.org) 
[block:api-header]
{
  "type": "basic",
  "title": "What is the DataCite Citation Formatter?"
}
[/block]
The Citation Formatter takes the metadata description of a DOI and uses the information to build a citation following more than 5,000 citation styles made available by the [citationstyles.org](http://citationstyles.org) project.

This service works across all Registration Agencies including Crossref, mEdra etc.
[block:api-header]
{
  "type": "basic",
  "title": "Who can use the DataCite Citation Formatter?"
}
[/block]
The Citation Formatter is open to the whole community. It is particularly designed for researchers to build reference lists under a convenient, simple and effective interface.
[block:api-header]
{
  "type": "basic",
  "title": "Format Citations"
}
[/block]
The Citation Formatter interface is very simple. Just fill the form including:

* The DOI of the resource you want to cite
* The citation style you want to use (you can use the drop down menu or type and auto-complete)
* The language if applies
