IGSN IDs for material samples are registered with metadata encoded in the [DataCite Metadata Schema](https://schema.datacite.org). The following are recommendations and best practices for IGSN ID metadata.

- [IGSN ID Metadata Recommendations](doc:igsn-id-metadata-recommendations) 
- [Enriching IGSN ID metadata in the DataCite Metadata Schema](doc:enriching-igsn-id-metadata-in-the-datacite-metadata-schema)

## Improving the DataCite Metadata Schema for material samples 

The IGSN–DataCite Metadata Management Working Group is proposing revisions to the DataCite Metadata Schema such that it better meets the needs of IGSN e.V. Members and the samples community more generally. DataCite and the IGSN e.V. are additionally developing samples Communities of Practice across domains to provide guidance on revisions. Changes proposed may be reflected in the DataCite Metadata Schema in the future. If you wish to offer additional feedback, please consult our support document on [providing DataCite Metadata Schema feedback](https://support.datacite.org/docs/metadata-feedback).
