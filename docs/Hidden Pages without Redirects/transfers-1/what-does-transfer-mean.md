There are a number of scenarios where it is necessary to transfer a DataCite prefix and DOIs from one repository to another. Whether an existing repository joins DataCite as a Direct Member or joins a consortium, the common thread is that a repository is moving from one DataCite Member to another Member -- this is when a repository needs to engage in the transfer process. 

As part of this process, a new Fabrica repository environment will be set up and the prefix(es) and DOIs belonging to the previous repository, under the previous Member, are transferred by the DataCite Support team. Technically, this is a straightforward process but requires some coordination between the parties involved.
