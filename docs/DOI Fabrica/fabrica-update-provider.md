Providers can update their settings. These settings will be used to populate the [Members page](https://www.datacite.org/members.html).

To modify the Provider settings, go to the Settings tab in the Provider dashboard. Click the *Update Provider* button in the upper right.

Enter any changes in the appropriate fields and click *Save* at the bottom of the page. **Note:** The Provider ID cannot be changed. 

For detailed descriptions of the fields, see [Field Descriptions for Provider Settings](doc:fields-provider-settings)
