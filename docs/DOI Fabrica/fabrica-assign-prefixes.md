To add a prefix, go to the *Prefixes* tab of the Provider dashboard and click the *Assign Prefix* button on the upper right.

On the next screen, select an available prefix from the dropdown box and click the *Assign Prefix* button. This action will add that prefix to your list of available prefixes. If there are no available prefixes, please [contact DataCite](doc:how-to-contact-datacite).

To assign this prefix to a Client, go to the Clients tab of the Provider dashboard and select the Client to whom you would like to assign the prefix. This will take you to the Client dashboard view. 
[block:image]
{
  "images": [

      "image": [

    }
  ]
}
[/block]
Go to the Prefixes tab of the Client dashboard. This tab shows all of the prefixes currently assigned to that Client. Click the *Assign Prefix* button on the right. 
[block:image]
{
  "images": [
    {
      "image": [

        963,

    }
  ]

[/block]
Select the desired prefix from the dropdown menu. Click the *Assign Prefix* button on the bottom of the page. This prefix will now be available to the Client to use when creating DOIs.
