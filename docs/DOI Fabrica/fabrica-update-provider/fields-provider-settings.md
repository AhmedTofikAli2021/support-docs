The following are descriptions of each field in the Provider Settings.  **All information in these fields will be displayed publicly on the [DataCite Members page](https://www.datacite.org/members.html).**
[block:api-header]
{
  "title": "Provider ID"
}
[/block]
The Provider ID is a unique identifier for each Provider. It must contain uppercase letters or numbers and should be a short meaningful string representing the Provider. 

**Note:** The Provider ID is established during onboarding and can't be modified.
[block:api-header]
{
  "title": "Provider Name"
}
[/block]
Full name of the Provider. This is typically the name of the organization, as the organization wants it displayed. For example, "The British Library". 
[block:api-header]
{
  "title": "Website"
}
[/block]
The website for the Provider. This is an optional field. 
[block:api-header]
{
  "title": "Contact Name"
}
[/block]
This is the name of the person responsible for the account. This person is considered to be the primary contact for any necessary DataCite or system communications. 
[block:api-header]
{
  "title": "Contact Email"
}
[/block]
The email address for the contact. This email address receives reset password requests. (This address should also subscribe to the [All Users mailing list](doc:how-to-contact-datacite)). 
[block:api-header]
{
  "title": "Contact Phone"
}
[/block]
The phone number for the contact. This is an optional field. 
[block:api-header]
{
  "title": "Country"
}
[/block]
The country where the Provider is located. This is an optional field. It will display publicly on the DataCite members page. 
[block:api-header]
{
  "title": "Description"
}
[/block]
A description of the Provider.
