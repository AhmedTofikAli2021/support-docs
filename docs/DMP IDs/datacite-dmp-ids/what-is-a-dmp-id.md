A DMP ID is a unique persistent identifier for a data management plan. The exact format of the DMP ID can change depending on the minting authority used (e.g. DOI, ARK, etc.).

DataCite supports DMP IDs since schema 4.4. The use of the DataCite DMP ID makes it possible to query [DataCite's Graph QL API ](doc:datacite-graphql-api-guide) to discover other identifiers related to a DMP.
