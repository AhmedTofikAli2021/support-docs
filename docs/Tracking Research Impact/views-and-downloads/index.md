1. [COUNTER Code of Practice](doc:counter-code-of-practice)

Read the [usage stats guidelines](doc:usage-stats) to learn more about how DataCite Commons already displays information about usage stats.

> 📘 Dataset usage
> 
> The current standard used to compute usage is exclusively for dataset resources. In future there will be standards for other types of resources, which will likely be very similar to the one used for datasets.
