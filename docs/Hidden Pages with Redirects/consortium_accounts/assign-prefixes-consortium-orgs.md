To add a prefix, go to the *Prefixes* tab of the Consortium Organization dashboard and click the *Assign Prefix* button on the upper left.

On the next screen, select an available prefix from the dropdown box and click the *Assign Prefix* button. This action will add that prefix to your list of available prefixes. If there are no available prefixes, please [contact DataCite](doc:how-to-contact-datacite).

Now that the prefix has been added to the list of available prefixes for the Consortium Organization, you may assign that prefix to a Repository. To do this, go to the Repositories tab of the Consortium Organization dashboard and select the Repository to whom you would like to assign the prefix. This will take you to the Repository dashboard view.

Go to the Prefixes tab of the Repository dashboard. This tab shows all of the prefixes currently assigned to that Repository. Click the *Assign Prefix* button on the left.

Select the desired prefix from the dropdown menu. Click the *Assign Prefix* button on the bottom of the page. This prefix will now be available to the Repository to use when creating DOIs.
