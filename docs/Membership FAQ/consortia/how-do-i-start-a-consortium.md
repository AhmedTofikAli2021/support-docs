If you have already identified a group of like-minded organizations that would like to join as consortium, you can [apply for membership](https://datacite.org/become.html). If you’d like to identify other organizations to start a consortium with, please don’t hesitate to contact us at [support@datacite.org](mailto:support@datacite.org).
