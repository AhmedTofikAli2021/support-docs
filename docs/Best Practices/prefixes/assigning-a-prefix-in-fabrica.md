A prefix is automatically assigned when a new Repository account is created in Fabrica. This can be done by Direct Members, Consortium Leads and Consortium Organizations. Please see the relevant documentation for more information:

Create a new Repository:
  * [Direct Members](doc:fabrica-create-repository)
  * [Consortium Leads and Consortium Organizations](doc:create-a-repository-consortium-organizations)
