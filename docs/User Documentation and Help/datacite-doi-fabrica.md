[block:api-header]
{
  "type": "basic",
  "title": "What is DataCite DOI Fabrica?"
}
[/block]
DataCite DOI Fabrica is a one-stop service to create and manage DOIs for your organization. DOI Fabrica is a service for DataCite Providers and Clients only. Providers use Fabrica to administer Client accounts and activities related to DOI registration. Clients use Fabrica to create and manage DOIs and their associated metadata.

[What is the difference between Members, Providers, and Clients?](doc:members-providers-and-clients)

[block:api-header]
{
  "title": "Which browser works with DOI Fabrica?"
}
[/block]
DOI Fabrica supports the latest versions of the following browsers: **Chrome**; **Firefox**; **Safari**; and **Microsoft Edge**, representing more than 90% of global web usage. Other browsers, such as the most recent version (version 11) of Internet Explorer are supported on a best as we can basis. The DataCite team is monitoring which browser and version the community is using to access DOI Fabrica, and will update the application as needed. 
[block:api-header]
{
  "title": "How to create a DOI Fabrica account"
}
[/block]
To obtain a DOI Fabrica account your organization needs to be a DataCite Provider or a Client. 

If your organization is a Client please contact your Provider for account credentials. For example, the London School of Economics (i.e., Client) would need to contact the British Library (i.e., Provider). 

If you are a Provider your credentials should have been provided during your onboarding process. If you do not yet have credentials for DOI Fabrica, please contact DataCite Support at support@datacite.org. 

In both cases, please provide the following information for the new DOI Fabrica account: 

* Your desired Provider or Client ID, which is a short set of initials that uniquely identifies your organization. For example, ANDS is the Provider ID of the Australian National Data Service.
* The name of your organization. 
* The name of a contact person responsible for the account. 
* The email address of the designated contact person. 

DataCite staff or your Provider will create an account and provide you with the Account ID, which will be your user name. The designated contact person will receive an automatic email from the DOI Fabrica system prompting them to set a password for the account.
