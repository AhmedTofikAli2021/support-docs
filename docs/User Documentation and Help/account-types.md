This page provides an overview of the types of accounts available to DataCite Providers and Clients, including permissions and account setup. (Learn more about the [differences between Members, Providers, and Clients](doc:members-providers-and-clients).) 
[block:api-header]
{
  "title": "Production Account"
}
[/block]
Each DataCite Provider or DataCite Client will have a "production account" that allows them access to DataCite services relevant for their user type. Clients can use their production account to create and manage DOIs. Providers can use their production account to create and manage Clients, including the assignment of DOI prefixes. 

Your production account works for DataCite DOI Fabrica (https://doi.datacite.org), our DOI creation and management portal, as well as for all of our APIs below. 
* REST API (https://api.datacite.org
