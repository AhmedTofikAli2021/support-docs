DataCite provides demo accounts for (we call it a *sandbox*) for users to test the DOI creation service through its Metadata Store (MDS). If you are curious about how the DOI creation process works this is a good place to start. Test accounts are for demonstration purposes only and are subject to deletion after a certain amount of time. 

If you are planning on becoming a DataCite Member or User and you would like to prepare or test your integration in advance, [contact us](doc:how-to-contact-datacite) and we will provide you credentials to access the test environment.
