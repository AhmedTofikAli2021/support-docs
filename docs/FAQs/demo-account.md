[block:api-header]
{
  "title": "About demo accounts"
}
[/block]
Demo accounts are intended for DataCite Members who have recently joined but are not yet ready to create active DOIs. A demo account allows you to configure your systems to automatically register and manage DOIs via API or to try out the functionality that's currently available in DOI Fabrica without the risk of creating live DOIs. To request a demo account, please contact [DataCite Support](mailto:support@datacite.org). 
[block:callout]
{
  "type": "warning",
  "title": "Please note:",
  "body": "Demo accounts are in our live production system. Demo accounts are restricted to creating only Draft DOIs using the demo prefix 10.5072. This is to prevent accidental creation of live DOIs."
}
[/block]

[block:api-header]
{
  "title": "Set up your Demo Account"
}
[/block]
After receiving your request via [DataCite support](mailto:support@datacite.org), DataCite staff will create a demo account for you. 

You will receive an automatically generated e-mail from DOI Fabrica containing a *Generate a password* link.

Clicking on *Submit* will set the password and will take you to the *Sign in* page. Click on the *Sign in* button in the upper right corner of your screen and enter your *Account ID* and the password. You will find your Account ID in the same system e-mail as the password link. It will be *DEMO.* followed by several capital letters, usually your organizational acronym.

[block:api-header]
{
  "title": "Create and Manage Draft DOIs"
}
[/block]
A demo account only allows the registration of Draft DOIs using the demo prefix 10.5072. Draft DOIs are not visible outside of DOI Fabrica and can be deleted. 

For detailed information on how to register and manage DOIs via the DOI Fabrica interface, please see [DataCite DOI Fabrica for Clients](doc:datacite-doi-fabrica-for-clients).

For detailed information on working with our APIs for Members, please see the [DataCite MDS API Guide](doc:mds-2) or the [DataCite EZ API Guide](doc:datacite-ez-api-guide).
