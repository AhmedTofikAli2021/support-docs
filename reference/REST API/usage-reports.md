The DataCite REST API provides usage reports in [SUSHI](https://www.niso.org/schemas/sushi) format. The API closely follows the [RESEARCH_DATA_SUSHI specification](https://app.swaggerhub.com/apis/COUNTER/researchdata-sushi_1_0_api/1.0.0#/).
